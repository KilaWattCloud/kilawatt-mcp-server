# Directory submission copy

## PulseMCP

**Short description:** MCP server for requesting GPU compute capacity and retrieving job status through four tools, including x402 payment workflows.

**Long description:** This MCP server provides tools to request GPU compute capacity, inspect x402 payment requirements, submit a confirmed x402 job, and retrieve job status. Configure the API key for `deploy_gpu_node`; x402 payment execution uses a locally configured wallet key and locally enforced spend caps.

**Tags:** gpu, compute, cloud, x402, payments, infrastructure

**Tools:** `deploy_gpu_node`, `x402_quote`, `x402_run_job`, `x402_job_status`

**Environment variables:**
- `KILAWATT_API_KEY`: Optional API key for `deploy_gpu_node`.
- `KILAWATT_X402_PRIVATE_KEY`: Wallet key used by `x402_run_job`.
- `KILAWATT_X402_MAX_USD_PER_JOB`: Local per-job spend cap, default `0.25`.
- `KILAWATT_X402_MAX_USD_PER_SESSION`: Local session spend cap, default `1.00`.
- `KILAWATT_BASE_URL`: Optional gateway endpoint override.
- `KILAWATT_X402_URL`: Optional x402 endpoint override.

**Repository:** https://github.com/KilaWattCloud/kilawatt-mcp-server  
**npm:** https://www.npmjs.com/package/kilawatt-mcp-server

It is now listed. `glama.json` describes the server as supporting account-based and x402 payment options, matching the available tools. The MCP Registry schema version and `mcpName` remain unchanged.
